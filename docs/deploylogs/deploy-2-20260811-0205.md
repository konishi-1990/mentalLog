### 起動しなかった理由
`.github/workflows/deploy-product.yml` のトリガーは以下のとおりで、
**base が `product` の PR がマージされたときのみ**デプロイが走る。

```yaml
on:
  pull_request:
    types: [closed]
    branches: [product]   # PR のマージ先（base）が product のもの
  workflow_dispatch:      # 手動再デプロイ用
```

本 PR の base は `main` のため、対象外。
マージ後の `gh run list` でも最新 run は PR #1 の 29298144838 のままで、新規 run は発生していない。
