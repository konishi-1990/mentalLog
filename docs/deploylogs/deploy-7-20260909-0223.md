## ⚠️ 未実施の手動作業（要対応）

**seeder は `script/deploy.sh` に含まれておらず自動実行されない。** 本番 VPS 上で以下が必要。

```bash
cd ~/Cde/mentallog/mentalLog
docker compose -f docker-compose.prod.yml exec -T php php artisan db:seed --class=ChecklistCategorySeeder
docker compose -f docker-compose.prod.yml exec -T php php artisan db:seed --class=ChecklistOptionSeeder
```

実行するまでの状態:

| 影響 | 内容 |
| --- | --- |
| カテゴリ説明文が出ない | `description` が NULL のため、摂取物への誘導文とクセの「超重要」が表示されない |
| 「何もできてない」の排他が効かない | `is_none` が false のままのため、他の回復行動と同時選択できてしまう |
| 「何もできてない」に効いた感を要求してしまう | 同上。`is_none` が false だと必須化の除外に乗らない |

**3つ目は新規入力を妨げるため、実質的に seeder 実行までは回復行動の入力導線が悪化する。**
デプロイ直後に実行することを推奨。

両 seeder は `updateOrCreate` のため冪等で、過去の選択レコードには影響しない。
