### フェーズ1: 死んでいた入力導線の修復

本番28日分で `effect_score` / `duration_min` が全件 NULL で `recoveryEffect()` が空を返し続けていた問題への対処。

| 対象 | 内容 |
| --- | --- |
| `app/Support/EffectLevels.php` | 新規。効いた感の3段階（効かなかった2 / 少し効いた5 / かなり効いた8）。**既定値は置かない** —— 既定値があると全件同値になり入力率だけ上がって分散が消える |
| `app/Support/DurationBuckets.php` | 新規。かけた時間の4択（15/30/60/120分）。任意入力のまま |
| `StoreLogRequest` | `effect_score` / `duration_min` を `Rule::in` に。`withValidator` で「`tracks_effect` かつ `is_none=false` の選択肢を選んだときだけ効いた感必須」 |
| `ChecklistOptionSeeder` | 「何もできてない」を `is_none => true` に。排他ロジックに乗り、必須化の対象からも外れる |
| `AnalyticsService::recoveryEffect()` | `is_none` を集計対象から除外 |
| `checklist_categories.description` | 新カラム（nullable）。摂取物への誘導文を出す。あわせて `form.blade.php` の `code === 'thought_habit'` 直書き（規約違反）を解消 |
| `form.blade.php` / `show.blade.php` | 3段階ラジオ＋選択式の時間。表示はラベル（3段階外の旧値は数値表記へフォールバック） |

### フェーズ2: 既存データで効く分析

**スキーマ変更なし・入力負担ゼロ・過去28件に遡って効く。**

| メソッド | 内容 |
| --- | --- |
| `stressSourceOverlap()` | 同日の○件数ごとの日数・平均。`logs` 起点なので**○が0件の日も落とさない** |
| `thoughtHabitCount()` | クセの個数ごとの平均（「特になし」は0個） |
| `autocorrelations()` | 前日→翌日の相関5組。連続していない日はペアにしない |
| `inputLag()` | 当日/翌日/それ以降の内訳と平均入力時刻。**カラム追加なし**（`created_at` から算出） |
| `coverage()` | 欠測バイアス（翌日欠測日 vs 翌日記録日）と `current_gap` を追加 |
| `correlations()` | n 降順＋\|r\| 降順に並べ替え、`reliable` フラグ（n<10 に「参考値」バッジ） |

ビュー: 分析画面に3カード追加、記録率カードに欠測バイアスと入力タイミング、
ダッシュボードに未記録連続バナー（ログ0件の初回利用時は出さない）。

`app/Services/LogService.php` は**変更なし**。`selection_meta` の受け渡しは既存実装で足りた。
