## ⚠️ 未実施の手動作業（要対応）

**seeder は `script/deploy.sh` に含まれておらず自動実行されない。** 本番 VPS 上で以下の実行が必要。

```bash
./bin/ssh.sh php artisan db:seed --class=ChecklistCategorySeeder
./bin/ssh.sh php artisan db:seed --class=ChecklistOptionSeeder
```

実行するまでの状態:

| 影響 | 内容 |
| --- | --- |
| 「摂取したもの」カテゴリが出ない | `intake` カテゴリのレコードが無いため、ログ入力フォームに表示されない |
| 回復行動の効果測定欄が出ない | `checklist_categories.tracks_effect` が既定値 false のままのため、所要時間・効いた感の入力欄が描画されない |

いずれも既存機能を壊すものではなく、新機能が出てこないだけ。フェーズ1（睡眠・持ち越し感・コントロール可能度・勤務形態）とフェーズ4（相手タグ）、フェーズ5・6（分析）はマイグレーションのみで動作するため、seeder 未実行でも利用できる。

両 seeder は `updateOrCreate` のため冪等で、既存の選択肢や過去ログには影響しない。
