## 2. テスト方針

- **Unit**：Service・モデルのロジック（純粋な計算・状態）。
- **Feature**：HTTPエンドポイント＋認可（実リクエスト）。
- **重点**：機微情報のため「他人のデータが見えない/操作できない（403）」を必ず検証。集計は固定データ→期待値で数値保証。
